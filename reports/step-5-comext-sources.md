# Källor för Steg 5 – Comext

- Eurostat, **API - Getting started for DS-prefixed datasets from Comext database**. Bekräftar separat API-bas för Comext och att fullständiga handelsdataset inte får hämtas utan filter.
- Eurostat, **API - Detailed guidelines - DS-prefixed datasets from Comext database**. Bekräftar samma separata endpoint och filtreringskrav.
- Eurostat, **Asynchronous API guidelines**, exempel `DS-045409`. Visar dimensionerna frekvens, reporter, partner, product, flow, time period och indicators samt datasetets mycket höga kardinalitet.
- Eurostat Statistics Explained, **Data sources / International trade statistics**. Beskriver Comexts centrala semantiska dimensioner: reporter, partner, flow, product, time och indicator.
