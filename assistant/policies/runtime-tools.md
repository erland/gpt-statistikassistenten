# Runtimeverktyg

De deklarerade Python-skripten är deterministiska referensimplementationer för källplanering, query-planering, beräkning, presentation och quality gate. Om runtime inte kan köra ett deklarerat skript får motsvarande logik utföras med tillgängligt kodverktyg, men samma gates och kontrakt ska följas. Externa data måste fortfarande verifieras mot officiell källa vid frågetillfället.
