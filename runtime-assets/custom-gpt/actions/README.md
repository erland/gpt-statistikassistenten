# Actions att lägga till i GPT Builder

Lägg in dessa som tre separata Actions. Autentisering: **None**.

- `scb-openapi.yaml`
- `eurostat-openapi.yaml`
- `comext-openapi.yaml`

SCB ger direkt tabellsökning/metadata/data. Eurostat och Comext använder metadata + en verifierad SDMX series-key. Brå har ingen Action i version 1.
