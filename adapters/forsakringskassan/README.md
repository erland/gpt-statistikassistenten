# Försäkringskassan

Försäkringskassan publicerar officiell statistik som öppna data, främst JSON/CSV med metadata i det publika statistik-API:t. Börja med datasetets metadata och följ endast distributions-URL:er som metadata anger. Exempel på områden är sjukpenning, sjukfall, föräldraförsäkring och andra socialförsäkringsförmåner.
