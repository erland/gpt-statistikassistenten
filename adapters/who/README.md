# WHO

WHO:s World Health Data Hub (data.who.int) är primär ingång för global hälsostatistik. Det äldre GHO OData-gränssnittet är utfasat/deprecated och ska inte byggas in som permanent kontrakt. Runtime ska identifiera aktuell indikator och använda officiell export/API från data.who.int eller WHO:s aktuella GHO-sidor, med tydlig metadata och proveniens.
