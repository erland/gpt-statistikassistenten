# Energimyndigheten

Använd Energimyndighetens officiella PxWeb-statistikdatabas för energiindikatorer, officiell energistatistik och prognoser. Navigera metadata först, välj tabell och dimensioner, och gör därefter ett begränsat POST-uttag. Ange Energimyndigheten som källa; bearbetade resultat ska märkas som bearbetning av deras statistik.
